2-Stage Deep Learning Surrogate Framework Combining Classification and Regression for Optimal Design of Electric Machines

A methodology for optimal IPMSM design that significantly reduces analysis time compared to FEM.

📌 연구 개요 (Overview)

Developed a 2-Stage Deep Learning Surrogate Framework combining a classification model for geometric feasibility and a regression model for performance prediction. This framework significantly reduces analysis time compared to Finite Element Method (FEM) while maintaining high accuracy for optimal IPMSM design.

🧑‍💻 연구 내용 (Research Details)

  • Construction of a classification model to pre-screen geometrical constraints
  • Training of a regression model to predict motor performance (torque, efficiency, etc.) for selected designs
  • Generation of FEM data and optimization of deep learning models

🛠️ 주요 기술 (Technical Features)

  • Deep Neural Networks (DNN): Multi-layer perceptron for surrogate modeling.
  • 2-Stage Architecture: Classification (Feasibility) + Regression (Performance).
  • Optimization: Robust design optimization using the surrogate model.
