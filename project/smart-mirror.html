Smart Mirror using Computer Vision

Selected personal project (KRW 5,000,000 grant) · Development in progress.

📌 프로젝트 개요 (Overview)

Developing a smart mirror using computer vision technology to provide useful information and interaction in daily life. This is a personal project supported by the Gyeonggi Gap-Year Program.

🛠️ 주요 기능 및 기술 (Technical Features)

  • Embedded System: Implementation using Raspberry Pi.
  • UI/UX: Information display interface design.
